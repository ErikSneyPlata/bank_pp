# Alcance remoto futuro

En esta entrega no se activa Supabase ni se configura Data API. Este directorio queda como nota del proyecto para una etapa posterior, si el alcance docente lo requiere.

Al usar contraseñas de texto simple en el ejercicio local, nunca publicar ni exponer la columna `contrasena` en una API remota. La integración remota requeriría un diseño de autenticación diferente aprobado para esa fase.
