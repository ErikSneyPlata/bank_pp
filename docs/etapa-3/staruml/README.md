# Archivos editables de StarUML

Los diagramas finales de esta adaptación son:

- `BankPP-diagrama-clases.mdj`: clases Java del dominio, herencia, abstracción, composición y agregación; no incluye el tipo Java `interface`.
- `BankPP-diagramas-formularios.mdj`: clases de formularios Swing con los componentes declarados como atributos y acciones como operaciones.

Los dos archivos se basan en los `.mdj` adjuntos como referencias. Abra cada archivo en StarUML con **File → Open**. Los `.puml` en `../uml` conservan las fuentes legibles y comparables con las clases implementadas.
