# Nota de alcance: Supabase

Esta etapa y la aplicación actual usan PostgreSQL local mediante JDBC. No hay cliente Supabase, Auth remoto, API, RLS ni RPC implementados.

La conexión a Supabase pertenece a una etapa futura solo si el curso y el alcance aprobado lo requieren. No se debe presentar esta nota como una función disponible ni configurar la aplicación con claves de Supabase.
